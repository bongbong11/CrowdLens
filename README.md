# CrowdLens 0.4.0

SillyTavern용 커뮤니티 반응 확장입니다. 확장을 열면 저장된 반응이 먼저 보이며 **반응 / 프로필 / 설정** 탭에서 관리합니다.

## 설치·업데이트

1. 확장 관리에서 `https://github.com/bongbong11/CrowdLens`를 설치하거나 업데이트합니다.
2. [서버 플러그인 ZIP](https://github.com/bongbong11/CrowdLens/raw/refs/heads/main/downloads/crowdlens-server.zip)을 풀어 `crowdlens` 폴더를 SillyTavern의 `plugins/`에 넣습니다.
3. `config.yaml`의 `enableServerPlugins: true`를 켜고 서버를 재시작한 뒤 브라우저를 새로고침합니다. 화면 확장과 서버 플러그인을 함께 업데이트해야 합니다.

SillyTavern 1.18.0 이상을 대상으로 하며 서버는 SillyTavern 루트에서 실행합니다. 별도 CORS 프록시는 필요 없습니다. 서버 ZIP에는 필요한 원본 플랫폼 지침이 포함되어 있습니다. 수동 복사 시에는 `server-plugin/`을 `plugins/crowdlens/`로 복사하고 저장소의 `prompts/community-reactions.json`도 그 안의 `prompts/` 폴더에 복사하세요.

CMD에서 서버를 끄고 SillyTavern 폴더에서 실행:

```cmd
curl.exe -fL "https://github.com/bongbong11/CrowdLens/raw/refs/heads/main/downloads/crowdlens-server.zip" -o "%TEMP%\crowdlens-server-update.zip" && powershell -NoProfile -Command "Expand-Archive -LiteralPath (Join-Path $env:TEMP 'crowdlens-server-update.zip') -DestinationPath '.\plugins' -Force"
```

## 열기

마법봉 메뉴의 CrowdLens 또는 **마법봉 옆 작은 돋보기 버튼**으로 엽니다. 기본 화면은 저장된 **반응** 탭입니다. RP 메시지 아래에는 피드를 붙이지 않습니다.

## 프로필 입력·판독

프로필 탭에서 캐릭터와 페르소나를 각각 설정합니다.

- 현재 카드/페르소나 시트를 포함할지 체크합니다.
- 캐릭터의 **주 로어북과 추가 연결 로어북**을 펼쳐 필요한 엔트리를 체크합니다.
- 페르소나의 **전역 로어북과 현재 페르소나에 지정된 로어북**도 같은 방식으로 선택합니다.
- **선택 저장** 후 **프로필만 판독**을 누릅니다.

시트가 로어북에만 있다면 현재 카드 시트를 제외하고 엔트리만 고를 수 있습니다. 비활성·빈 엔트리는 선택 목록에서 제외합니다. 선택한 엔트리가 없어지거나 연결이 바뀌면 오류를 표시하며 임의로 다른 내용을 대신 보내지 않습니다. 같은 본문은 중복해서 보내지 않습니다.

**프로필만 판독**은 영어 사회적 프로필만 작성·저장합니다. RP 응답이 없어도 사용할 수 있으며, JEV 판독이나 커뮤니티 반응 생성·삭제를 하지 않습니다. 실패하면 기존 프로필을 보존합니다. 선택은 캐릭터·페르소나·브랜치별로 저장하며 다시 열어 확인할 수 있습니다.

직업·인지도·대외평판·지인 관점·공개정보를 짧게 정리합니다. 반응을 만들기 전에 선택한 입력의 프로필 판독을 완료해야 합니다. 선택한 입력이 같으면 저장한 프로필을 재사용하며, 반응 버튼이 프로필을 자동으로 다시 판독하지 않습니다. 원본 카드·페르소나·로어북·채팅은 변경하지 않습니다. 세계관이나 비밀을 자동으로 공개 정보로 취급하지 않도록 지시합니다.

## 반응 생성·저장 관리

설정 탭에서 사용을 켜고 작성용 SillyTavern 연결 프로필을 선택합니다. 선택하지 않으면 서버에 저장된 현재 연결 설정을 사용합니다. RP의 연결 설정을 바꾸지는 않습니다.

반응 탭의 **현재 장면 반응 만들기**를 누를 때 최신 RP 응답과 앞선 최대 5개 메시지를 읽습니다. 자동 생성은 없습니다. 입력을 준비하는 동안 다른 응답이 생겨도 버튼을 누른 순간의 장면을 사용합니다.

저장된 반응 목록에서 결과를 선택해 보고 **선택 반응 삭제**로 지울 수 있습니다. RP 메시지의 스와이프·리롤·수정·삭제로 이미 저장한 반응을 자동 변경하거나 지우지 않습니다. 새 반응이 필요하면 생성 버튼을 다시 누르세요. 채팅·브랜치별로 보관하며 플랫폼별 탭으로 표시합니다. 팬덤·안티·지인 같은 내부 집단 분류는 화면에 표시하지 않습니다.

## 생성 설정

- **직접 체크:** 체크한 커뮤니티만 연결 모델로 생성합니다. JEV 키와 JEV 호출이 필요하지 않습니다.
- **자동 선택:** JEV가 장면의 공개성, 적합한 커뮤니티, 반응 가능한 집단을 판정하고 연결 모델이 글을 작성합니다. JEV 제공자는 공홈 TypeSafe와 NanoGPT 두 개입니다. NanoGPT 키는 Billing이 `Subscription only`여야 합니다.
- **댓글 양:** 적게 3개 / 중간 6개 / 많이 10개, 커뮤니티당 기준입니다.
- **출력 언어:** 영어 또는 한국어. 한 응답에 영어 초안과 한국어를 두 벌로 출력하지 않습니다.
- **영어 피드 번역:** 누른 커뮤니티의 글만 한국어로 번역하고 저장합니다. 이후 원문/번역 전환과 재접속은 추가 모델 요청을 하지 않습니다.
- **공통 음지 모드:** 한 번 체크하면 선택한 커뮤니티 전체에 적용합니다. 거친 성격 비중을 높이고 가상의 관리자 삭제 표시를 사용하지 않습니다. 욕설을 순화하는 사후 치환 필터는 없습니다.
- **브랜치:** 기본 브랜치에서 시작하며 `＋ 추가`를 눌렀을 때만 새 이름을 입력합니다.

최대 출력은 기본 8,192, 설정 범위 8,000~32,768입니다. 최대값이 실제 사용량은 아닙니다. 댓글 양과 선택한 커뮤니티가 많을수록 비용이 늘 수 있습니다. 일부 모델은 내부 추론도 출력 한도에 포함합니다. 한도 초과나 파싱 실패 때 유료 요청을 자동 반복하지 않습니다.

## 플랫폼 프롬프트

설정의 **커뮤니티 프롬프트 편집**에서 플랫폼별 본문과 공통 지침을 확인·수정한 뒤 저장할 수 있습니다. 기본 9개 플랫폼은 Twitch, Reddit, Twitter/X, Discord, YouTube, AO3, Instagram, TikTok, 4chan입니다. SMS는 선택지에서 제외합니다.

원본 지침은 요약하지 않고 전달합니다. 동일한 공통 지침은 모델 요청에 한 번만 넣고 각 플랫폼이 참조합니다. 출력 언어와 JSON 형식은 짧은 별도 지시로 정합니다. 여러 JSON을 가져오면 기존 목록에 합치고 같은 ID는 새 파일 내용으로 갱신합니다. 수정본은 서버 설정에 저장하며 원본 파일은 바꾸지 않습니다.

개인 성격은 여러 축의 주사위를 조합하고 문화권·집단과 별도로 구성합니다. 한 커뮤니티 안에서도 미국·유럽·동아시아 맥락의 서로 다른 개인 말투를 섞으며 플랫폼 하나를 특정 지역으로 고정하지 않습니다. 실제 말투·번역 뉘앙스는 연결 모델의 지시 이행에 따라 달라집니다. 외부 커뮤니티에 실제 게시하지 않습니다.

## 저장·취소·모바일

계정별 `data/<account>/crowdlens/`에 설정·JEV 키·프로필·입력 선택·채팅/브랜치 반응·작업 상태를 저장합니다. 키는 브라우저에 반환하지 않습니다. 기존 프로필과 반응의 데이터 식별자는 유지합니다.

작업은 서버에서 실행하며 확장 창이나 브라우저 탭을 닫아도 계속됩니다. 다시 열면 저장 결과를 불러옵니다. 설정에서 진행 중 작업을 취소할 수 있고 제한 시간은 5분입니다. 서버 자체가 종료되면 중단되며 자동으로 유료 재실행하지 않습니다.

화면은 모바일 세로 스크롤과 가로 플랫폼 탭을 지원합니다. 돋보기 버튼은 기존 도구 모음의 배치 흐름을 따릅니다. HTTPS 전용 UUID 기능에 의존하지 않으므로 일반 HTTP 주소에서도 표시됩니다. 실제 네트워크 연결 권한은 SillyTavern/Tailscale 설정을 따릅니다.
